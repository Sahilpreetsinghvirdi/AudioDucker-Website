# Audio Ducker Website

Landing page for [Audio Ducker](https://github.com/Sahilpreetsinghvirdi/AudioDucker) — a Windows tool that keeps your music playing at a low volume while you watch lectures and courses, then brings it back up when you pause.

A single self-contained [`index.html`](index.html) with inline CSS and JavaScript. No build step, no dependencies, no frameworks — open it in any browser or host it on any static host (GitHub Pages, Netlify, etc.).

## Preview

Open `index.html` directly in a browser, or serve the folder:

```powershell
npx serve .
```

## What's inside

- Hero + one-line install command with a copy button
- Features, how-it-works steps, FAQ
- Download links to the [GitHub Releases](https://github.com/Sahilpreetsinghvirdi/AudioDucker/releases) page
